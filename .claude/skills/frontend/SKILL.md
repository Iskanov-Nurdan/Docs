# Фронтенд ALI trade

Совместная работа с таблицами. Фронтенд — `frontend/`,
бэкенд Django/DRF — `backend/`, всё через nginx на одном origin.

## Стек

React 18.3 · TypeScript 5.7 (strict) · Vite 6 · Tailwind 3.4 · Zustand 5 ·
react-router-dom 6 · Yjs 13.6 + y-indexeddb (совместная работа).

Библиотеки **не добавлять** без явной необходимости: UI-китов нет,
дат-библиотек нет (`Intl`), набор значков свой — `components/icons.tsx`.

## Раскладка каталогов

```
frontend/src/
  api/          client.ts — транспорт (JWT, refresh); index.ts — по методу на эндпоинт
  components/   переиспользуемые примитивы (Modal и т.п.)
  spreadsheet/  редактор таблиц: книга Yjs, сетка, формулы, поиск по листу
  pages/        страницы роутера, по файлу на страницу
  store/        Zustand-сторы
  types/        общие типы (единственный источник моделей API)
  utils/        чистые функции (форматирование дат и т.п.)
  websocket/    DocumentProvider — свой протокол поверх WebSocket
```

Импорты — только через алиас `@/` (`@/api`, `@/types`, `@/store/auth`).
Относительные пути допустимы лишь внутри одной папки (`./extensions`).

## Порядок работы

1. Прочитать соседние файлы того же слоя и повторить их стиль.
2. Новый вызов сервера — сначала метод в `src/api/index.ts`, потом использование.
   `fetch` в компонентах запрещён.
3. Новый тип ответа сервера — в `src/types/index.ts`, а не рядом с компонентом.
4. После правок: `npm run typecheck` (обязательно) и `npm run lint`.

## Стили

Только Tailwind-классы. Инлайновый `style` — исключение ровно для вычисляемой
геометрии (миллиметры листа, цвет участника), не для оформления.

Цвета берутся из семантических токенов, объявленных в `tailwind.config.js` и
`index.css`: `surface`, `surface-muted`, `ink`, `ink-muted`, `accent`,
`hairline`. Хардкод `bg-white`/`text-gray-800` для интерфейса запрещён —
он ломает тёмную тему. Палитра Tailwind (`red-600`, `emerald-600`, `amber-*`)
допустима только для смысловых акцентов: ошибка, успех, метки в тексте.

Классы по условию собираются массивом с `.join(' ')`, а не конкатенацией строк:

```tsx
className={[
  'rounded border px-2.5 py-1.5 text-sm',
  active ? 'border-accent bg-surface-muted' : 'border-hairline',
].join(' ')}
```

Оформление самого документа живёт в `index.css` в `@layer components`
(`.prose-editor`, `.annotation-*`) — там же правила `@media print`.

## Значки

Только `components/icons.tsx` — эмодзи и юникод-символы в интерфейсе
запрещены: они разные в каждой системе, не наследуют цвет и рядом с текстом
выглядят чужеродно.

* новый значок дорисовывается в тот же файл: контур 1,5, сетка 24×24,
  скруглённые концы, цвет через `currentColor`;
* размер задаётся пропсом `size`: 16 — в списках и меню, 18 — в шапке,
  26–30 — на плитках;
* сам значок скрыт от чтения с экрана; подпись даёт `aria-label` кнопки.

## Форма элементов

Всё, что выпадает или переключает, — овальное (`rounded-full`): списки,
кнопки-значки, вкладки листов, поле поиска, кнопки действий. Прямоугольными
остаются поля ввода в формах и карточки — иначе форма входа и таблица
«поплывут». Всплывающие панели — `rounded-2xl`.

Выпадающий список — только `components/Select.tsx`, `<select>` в интерфейсе
не используется: системный список рисует операционная система, его нельзя
ни скруглить, ни подсветить выбранное, ни дать пункту пояснение. В своём уже
есть клавиатура (стрелки, Enter, Escape, переход по набранным буквам),
галочка у выбранного и подсказка под названием (`hint`).

## Мобильные экраны в первую очередь

Базовые классы — под узкий экран, `sm:`/`md:` расширяют. Проверенные приёмы
проекта: высота экрана — `min-h-dvh`/`h-dvh` (не `vh`); боковая панель на узком
экране занимает его целиком, а лист прячется (`sidePanel ? 'hidden sm:block' : ''`);
модальное окно снизу на телефоне и по центру на десктопе.

## Обязательные состояния

Любой экран с загрузкой данных показывает все четыре состояния:

* загрузка — `<p className="p-12 text-center text-ink-muted">Загрузка…</p>`;
* ошибка — текст плюс кнопка «Повторить», вызывающая ту же функцию загрузки;
* пусто — заголовок и подсказка, что делать дальше;
* данные.

Ошибку сервера показывать сообщением из `ApiError.message` (бэкенд отдаёт
человеческий текст в `detail`), запасной вариант — своя фраза на русском.

## Доступность

Это требование ТЗ, а не пожелание. В каждом интерактивном элементе:

* `type="button"` у всех кнопок вне форм;
* `aria-label` там, где подпись — символ (`☆`, `🗑`, `←`);
* `aria-pressed` у переключателей, `aria-current="page"` у активной вкладки;
* `role="status"` + `aria-live="polite"` у меняющихся статусов (автосохранение);
* `role="alert"` у сообщений об ошибке;
* фокус виден всегда — глобальный `:focus-visible` в `index.css` не отключать;
* модальные окна — только через `components/Modal.tsx`: там уже есть ловушка
  фокуса, возврат фокуса и Escape.

## Комментарии и язык

Интерфейс, комментарии и сообщения — по-русски. Идентификаторы — по-английски.

Комментарий пишется, когда неочевидно **почему** так, а не что делает код.
Формат — как в существующих файлах: `/** Одна строка */` над компонентом или
функцией, многострочный блок в начале файла для непростых модулей.

Не комментировать очевидное (`// установить состояние`).

## Движение

Интерфейс должен отзываться, а не мигать. Правила:

* переходы цвета, рамки и тени у интерактивных элементов заданы глобально
  в `index.css` — руками `transition-colors` на каждую кнопку не вешать;
* появление содержимого — классы `.animate-rise` (списки, пустые состояния),
  `.animate-pop` (меню, окна), `.animate-fade` (подложки), `.animate-slide`
  (боковая панель на телефоне). Длительность 140–180 мс: длиннее ощущается
  медленным, короче — дёрганым;
* вместо надписи «Загрузка…» на списках — `.skeleton` в раскладке будущего
  списка: данные встают на место, ничего не прыгает. Для читалки экрана
  рядом остаётся `role="status"` с текстом;
* блок `prefers-reduced-motion` в `index.css` отключает всё разом — не
  обходить его собственными анимациями в компонентах.

## Права

Уровней три, и они не про документ, а про систему:

* **пользователь** — работает со своими таблицами;
* **администратор** (`is_staff`) — видит людей и сводку, заводит учётные
  записи, закрывает доступ;
* **главный админ** (`is_superuser`) — создаётся `createsuperuser`, вдобавок
  назначает администраторов.

Самостоятельной регистрации нет: страницы `/register` не существует, форма
входа сообщает, что учётную запись заводит администратор. Не возвращать её
«для удобства» — это решение о том, кто попадает в систему.

Страница `/admin` закрыта `AdminOnly`, пункт меню показывается по `is_staff`.
Проверка на клиенте — удобство, а не защита: решает всегда сервер
(`IsAdmin` плюс правила в `apps/users/admin_api.py`). Недоступное действие
показываем отключённым с пояснением, а не прячем — иначе человек не поймёт,
почему у соседа кнопка есть, а у него нет.

## Данные и состояние

* Глобально — только то, что нужно многим страницам (сейчас: `store/auth.ts`).
  Остальное — локальный `useState` на странице.
* Загрузка данных — `useCallback` + `useEffect`, чтобы кнопка «Повторить»
  и обновления по событию вызывали ту же функцию.
* Поиск и другой ввод, дергающий сервер, — с задержкой 300 мс через
  `setTimeout` в `useEffect` с очисткой.
* Оптимистичное обновление списка после действия (звезда, удаление) — правкой
  локального массива, без перезагрузки всего списка.

## TypeScript

`any` запрещён. Для неизвестных данных — `unknown` с сужением. Пропсы —
локальный `type Props = { … }`, не `interface`, не `React.FC`.

Экспорт компонентов — именованный (`export function DocsPage()`),
`export default` не используется.

## Таблицы

Документ — это книга: листы с ячейками. Другого вида документов в системе нет,
поля печатного листа (формат, поля, ориентация) убраны вместе с редактором текста.

* ячейка — отдельная `Y.Map`, а не поле в общем объекте: двое, правящих
  соседние ячейки, не спорят за одну запись;
* хранятся только заполненные ячейки, пустая сетка не занимает ничего;
* формулы считает `spreadsheet/formula.ts` — имена функций русские
  (`СУММ`, `ЕСЛИ`), английские заведены псевдонимами;
* в снимок для сервера кладётся и введённое (`value`), и посчитанное
  (`display`): сервер формулы не считает, а в выгрузку и поиск нужны числа;
* сохранённое содержимое (история версий, публичная страница) рисует
  `SheetSnapshotView` — проверяя вид через `isSheetContent`: снимок мог быть
  сделан прежним форматом;
* обсуждение и предложения правок к таблице не подключаются: они опираются на
  позиции в тексте;
* цвет ячейка берёт по смыслу (`spreadsheet/statuses.ts`), двумя способами:
  по слову («просрочка», «налог», «在途», «overdue» — четыре языка в одном
  списке, сверка по началу слова после приведения ё/ө/ү/ң) и по времени —
  колонка со сроком узнаётся по заголовку («Прибытие», «Срок», «到达») и
  краснеет сама, когда время прошло. Закрытая строка («Готово», «Отменён»)
  не краснеет: рейс приехал. Порядок правил важен — «не оплачено» проверяется
  раньше «оплачено». Ручная заливка сильнее обеих подсказок;
* цвета по времени пересчитываются раз в минуту таймером в `Grid`: срок
  истекает сам, без правки документа, и без таймера красное появлялось бы
  только после следующего нажатия;
* деньги — `spreadsheet/money.ts`: в колонку «Сумма» пишут сомы, а хранится
  и показывается доллар со значком — пересчёт идёт при вводе по курсу НБ КР
  (`store/rates.ts`, эндпоинт `rates/usd/`, кеш на сутки). Число со значком
  доллара второй раз не пересчитывается, текст («по договору») остаётся как
  есть, а без курса сумма остаётся в сомах и помечается сомами. Значение
  и формат пишутся одной транзакцией: пересчёт отменяется одним Ctrl+Z.
  «Транзит» — та же денежная колонка, но уже в долларах: в ячейке предлагаются
  суммы из общего справочника (`transit-amounts/`, правит администратор на
  странице «Точки и маршруты»), при пустом справочнике — запасные 200/300/500,
  а свой «Список значений…» столбца важнее и того и другого;
* поиск по листу — Ctrl+F (`SheetFind`): ищет и по введённому, и по
  посчитанному, перебирая только заполненные ячейки. Выделение при переходе
  к найденному ставится снаружи, поэтому сетка сама доводит до него прокрутку.
  По умолчанию поиск идёт по колонке с номером машины (`VEHICLE_COLUMNS`,
  `FindOptions.col`), а найденная строка подсвечивается жёлтым целиком: ищут
  рейс, а не ячейку. Галочка снимается — тогда ищется весь лист. С привязкой
  к колонке поиск по всем листам недоступен: её номер на соседнем листе другой.

## API

Карта эндпоинтов и правила транспорта — `references/api.md`.
Коротко: `request()` сам подставляет JWT и обновляет пару токенов при 401,
`204` возвращает `undefined`, ошибки бросает `ApiError` с `status`, `code`,
`fields`.

## Чего не делать

* Не хранить токены нигде, кроме `tokens` из `@/api`.
* Не звать `window.alert`/`confirm` в новом коде — использовать `Modal`
  (в старом коде это остаётся, переписывать попутно не обязательно).
* Не дублировать форматирование дат — брать `@/utils/date`.
* Не создавать «универсальные» компоненты заранее: выносить в `components/`
  только то, что уже используется дважды.
